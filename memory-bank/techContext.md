## Environment Variables (.env)

### Required Variables
```bash
# Base search URL (brand to scrape)
BASE_URL=https://www.1mg.com/search/all?name=mankind

# Maximum products to scrape
MAX_PRODUCTS=100

# Output folder name (also used as default company name)
OUTPUT_FOLDER=mankind
```

### Optional Variables
```bash
# Gemini API key (optional - falls back to CSS selectors if missing)
GEMINI_API_KEY=your_api_key_here

# Browser mode (default: False = visible browser)
HEADLESS=False

# Proxy bypass for corporate networks (default: False)
USE_PROXY_BYPASS=False
```

### Variable Details

#### `BASE_URL`
- Full search URL from 1mg.com
- Example brands: `mankind`, `cipla`, `himalaya`, `dr-reddy`
- Format: `https://www.1mg.com/search/all?name={brand}`

#### `OUTPUT_FOLDER`
- **Dual purpose**: 
  1. Directory name for output files
  2. Default company name (capitalized)
- Examples: `mankind` → folder `mankind/`, company `Mankind`

#### `GEMINI_API_KEY`
- Get from: https://ai.google.dev/
- Free tier: 60 requests/minute, 1500 requests/day
- **Optional**: System works without it (CSS fallback)

#### `HEADLESS`
- `True`: Browser runs in background (faster, no GUI)
- `False`: Browser window visible (useful for debugging, inspection)
- **Note**: In non-headless mode, script waits for Enter before closing browser

#### `USE_PROXY_BYPASS`
- `True`: Bypass proxy for localhost (corporate environments)
- `False`: Use system proxy settings
- **When to use**: If you see "Failed to initialize WebDriver" with proxy errors

## Technical Constraints

### 1. Network Requirements
- **Internet connection**: Required for scraping and LLM API
- **Firewall**: Must allow:
  - HTTPS to www.1mg.com
  - HTTPS to generativelanguage.googleapis.com (Gemini API)
  - ChromeDriver download (first run only)
- **Proxy**: Supported via system settings or `USE_PROXY_BYPASS`

### 2. System Requirements
- **RAM**: 2GB minimum, 4GB recommended
- **Disk**: 500MB for dependencies + space for images
- **CPU**: Any modern CPU (LLM processing happens on Google servers)

### 3. Rate Limiting
- **1mg.com**: No official rate limit, but:
  - 3-second delays between requests (anti-bot)
  - Cloudflare protection may trigger if too aggressive
- **Gemini API**: Free tier limits:
  - 60 requests/minute
  - 1500 requests/day
  - Retry logic handles temporary exhaustion

### 4. Browser Compatibility
- **Chrome**: Primary supported browser
- **Chromium**: Should work (not tested)
- **Firefox/Edge**: Not supported (Selenium config specific to Chrome)

### Common Issues

#### Issue: "ChromeDriver not found"
**Solution**: 
- Ensure Chrome browser is installed
- Check internet connection (for auto-download)
- Try: `pip install selenium --upgrade`

#### Issue: "Failed to initialize WebDriver" (proxy error)
**Solution**:
```bash
# In .env:
USE_PROXY_BYPASS=True
```

#### Issue: "Cloudflare bot protection triggered"
**Solution**:
- Use non-headless mode: `HEADLESS=False`
- Add more delays (edit `link_fetcher.py` sleep times)
- Try different time of day
- Use VPN or different IP

#### Issue: "Gemini API quota exceeded"
**Solution**:
- Wait for quota reset (daily)
- System automatically falls back to CSS selectors
- Reduce `MAX_PRODUCTS` to stay within limits

#### Issue: "Image download connection reset"
**Solution**:
- Already handled with 3 retries + exponential backoff
- If persistent: Check corporate firewall/proxy
- Images are cached (re-running skips existing files)

## Platform-Specific Notes

### Windows
- Shell: `cmd.exe` or PowerShell
- Path separators: `\` (handled by `os.path.join()`)
- ChromeDriver logs: `NUL` device

### Linux/macOS
- Shell: Bash/Zsh
- Path separators: `/` (handled by `os.path.join()`)
- ChromeDriver logs: `/dev/null`
- May need: `sudo apt-get install chromium-browser` (Linux)

### Corporate Environments
- **Proxy**: Use `USE_PROXY_BYPASS=True`
- **SSL**: May need custom CA certificates (not currently supported)
- **Antivirus**: May block ChromeDriver (add exception)
